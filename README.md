# บันทึกเสียง (Android)

แอปบันทึกคำพูดเป็นข้อความแบบเรียลไทม์ และบันทึกเสียงเป็นไฟล์ไปพร้อมกัน
**ไม่ใช้ AI ไม่ต้องใช้ API key และไม่มีค่าใช้จ่าย** ใช้ระบบแปลงเสียงเป็นข้อความที่มีอยู่แล้วในมือถือ Android

## ฟีเจอร์

- **ถอดข้อความแบบเรียลไทม์** เลือกได้ 16 ภาษา เช่น ไทย เกาหลี อังกฤษ ญี่ปุ่น จีน
- **บันทึกเสียงเป็นไฟล์ไปพร้อมกัน** (.m4a ประมาณ 20 MB ต่อชั่วโมง)
  - แตะ **▶ เวลา** หน้าประโยคเพื่อฟังเสียงช่วงนั้น ระหว่างฟังจะไฮไลต์ประโยคที่กำลังพูดอยู่
  - **💾 เก็บไฟล์เสียง** บันทึกลงโฟลเดอร์ `Recordings/LiveNotes` ในเครื่อง
  - **🎧 แชร์เสียง** ส่งผ่าน LINE, KakaoTalk, Drive และแอปอื่นๆ
- **ช่วยให้ถอดข้อความแม่นขึ้น**
  - ฟังต่อเนื่องไม่ขาดช่วงระหว่างประโยค (Android 13 ขึ้นไป)
  - 📌 **คำเฉพาะที่ใช้บ่อย**: ใส่ชื่อคน ชื่อบริษัท หรือศัพท์เฉพาะ ระบบจะเลือกคำเหล่านี้ก่อน
  - 🔁 **แก้คำผิดอัตโนมัติ**: เช่น `ไลน์โอเอ = LINE OA`
  - **⋯ เลือกคำอื่น**: ระบบเก็บสิ่งที่อาจได้ยินไว้ถึง 5 แบบ แตะเพื่อเลือกแบบที่ถูก
  - ประโยคที่ระบบไม่ค่อยมั่นใจจะ **ขีดเส้นใต้สีส้ม** ให้ตรวจดูได้ง่าย
  - ใส่เครื่องหมายวรรคตอนอัตโนมัติ (Android 13 ขึ้นไป)
- แตะที่ข้อความเพื่อแก้ไขเองได้ แล้วคัดลอกหรือแชร์ข้อความทั้งหมดพร้อมเวลา
- ประวัติบันทึกทั้งหมดอยู่ในเครื่อง (📁)

## ความต้องการของเครื่อง

- **Android 10 ขึ้นไป**
  - **Android 13 ขึ้นไป** ถึงจะบันทึกเสียงพร้อมถอดข้อความได้ ถ้าต่ำกว่านี้จะถอดข้อความได้อย่างเดียว
- มี **แอป Google** ในเครื่อง เพราะเป็นตัวแปลงเสียงเป็นข้อความ
- ต้องต่ออินเทอร์เน็ต ยกเว้นเปิดโหมดออฟไลน์และดาวน์โหลดภาษาไว้แล้ว

> มือถือบางรุ่นอาจใช้ระบบถอดเสียงที่รับเสียงจากแอปโดยตรงไม่ได้ ถ้าเป็นแบบนั้น แอปจะแจ้งเตือนแล้วถอดข้อความต่อโดยไม่บันทึกเสียง

## เคล็ดลับให้ถอดข้อความแม่นขึ้น

1. เลือก **ภาษาที่พูด** ให้ตรง ถ้าพูดเกาหลีแต่ตั้งเป็นไทย ผลจะผิดเกือบทั้งหมด
2. ถือมือถือให้ห่างปากประมาณ 20–50 ซม. และหลีกเลี่ยงเสียงพัดลม เพลง หรือคนคุยกันข้างๆ
3. พูดเป็นประโยค และเว้นจังหวะสั้นๆ ระหว่างประโยค
4. ใส่ **คำเฉพาะที่ใช้บ่อย** เช่น ชื่อคนในทีม ชื่อสินค้า หรือศัพท์งาน
5. เจอคำที่ถอดผิดซ้ำๆ ให้กด **⋯ → เพิ่มคู่คำ** ครั้งต่อไประบบจะแก้ให้เอง
6. อัปเดตแอป Google ให้เป็นเวอร์ชันล่าสุด

## วิธีสร้างไฟล์ APK

### วิธี A: ให้ GitHub สร้างให้ (ไม่ต้องติดตั้งโปรแกรม)

1. สมัครหรือล็อกอินที่ https://github.com แล้วกด **New repository** ตั้งชื่อเช่น `LiveNotes` (เลือก Private ได้) แล้วกด **Create**
2. ในหน้า repo กด **uploading an existing file** แล้วลาก **ทุกอย่างที่อยู่ในโฟลเดอร์ LiveNotes** ไปวาง แล้วกด **Commit changes**
   ⚠️ ต้องมีโฟลเดอร์ `.github` ไปด้วย (บน Mac กด `Cmd + Shift + .` เพื่อให้แสดงโฟลเดอร์ที่ถูกซ่อน)
3. ไปที่แท็บ **Actions** รองาน **Build APK** ประมาณ 3–5 นาทีจนขึ้นเครื่องหมายถูกสีเขียว ✅
4. คลิกงานนั้น แล้วดาวน์โหลด **LiveNotes-apk** ที่หัวข้อ **Artifacts** จะได้ไฟล์ zip ที่มี `app-debug.apk` อยู่ข้างใน

### วิธี B: ใช้ Android Studio

1. ติดตั้ง Android Studio จาก https://developer.android.com/studio
2. **File → Open** แล้วเลือกโฟลเดอร์ `LiveNotes` รอให้โปรแกรมโหลดเสร็จ
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
4. ไฟล์อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

## ติดตั้งลงมือถือ

1. ส่งไฟล์ `app-debug.apk` เข้ามือถือ เช่น ผ่าน LINE, Google Drive หรือสาย USB
2. แตะเปิดไฟล์ แล้วอนุญาต **ติดตั้งแอปจากแหล่งที่ไม่รู้จัก**
3. ถ้า Play Protect เตือน ให้กด **ติดตั้งต่อ** (เตือนเพราะแอปไม่ได้มาจาก Play Store)
4. เปิดแอป กดไมค์ แล้วอนุญาตให้ใช้ไมโครโฟน

## ข้อควรรู้

- ถ้าออกจากแอป การบันทึกจะหยุด ระหว่างบันทึก หน้าจอจะไม่ดับเอง
- ไฟล์เสียงและบันทึกเก็บไว้ในแอป ถ้าลบแอป ไฟล์จะหายไปด้วย ควรกด **💾 เก็บไฟล์เสียง** ไว้ก่อน
- ถ้าติดตั้งทับเวอร์ชันเดิมไม่ได้ (ขึ้นว่าแพ็กเกจขัดแย้ง) ให้เก็บไฟล์เสียงที่ต้องการออกมาก่อน แล้วลบแอปเก่าแล้วติดตั้งใหม่ เพราะไฟล์ที่ GitHub สร้างแต่ละครั้งใช้ลายเซ็นต่างกัน

## โครงสร้างโปรเจกต์

```
app/src/main/
├── AndroidManifest.xml
├── java/com/livenotes/app/
│   ├── MainActivity.java   ← เปิดไมค์ + ส่งเสียงให้ระบบแปลงเสียงเป็นข้อความ + เล่นเสียง + เซฟ/แชร์ไฟล์
│   └── AacWriter.java      ← เข้ารหัสเสียงเป็นไฟล์ .m4a
└── assets/index.html       ← หน้าจอและฟีเจอร์ทั้งหมด
```
